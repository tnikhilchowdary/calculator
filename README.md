# React Calculator

A basic calculator built using **React** and **useState hook** to perform arithmetic operations like addition, subtraction, multiplication, and division.

---

## Features
- Add, Subtract, Multiply, Divide two numbers
- Handles invalid inputs and division by zero
- Uses `useState` for state management
- Clean and user-friendly interface
